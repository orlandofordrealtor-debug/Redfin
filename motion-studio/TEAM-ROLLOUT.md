## 2. Quick start for agents (60 seconds)

| Step | What you do | Tip |
|---|---|---|
| **Open** | Double-click `motion-studio.html` in Chrome or Edge | No install, no login, works offline |
| **Start** | Pick a template or click **Describe it** | Describe it reads your notes and fills fields for you |
| **Content** | Fill the fields in the checklist | Green = ready. Amber = would make it better. Red = required |
| **Look** | Keep **Redfin Glass** or try another look | The Redfin brand switch re-skins every look |
| **Format** | Pick sizes, length and sound | 9:16 for Reels/TikTok/Stories, 4:5 for feed posts |
| **Polish** | Edit any scene's words, timing or camera move | Hide scenes you don't need |
| **Export** | Download MP4, poster, GIF or storyboard | **Reset** (top bar) starts over at any time |

## 4. Inputs that make it great

- **Photos:** 5–8 bright, horizontal exterior and interior shots for listings. Tall graphics and
  posters automatically get portrait cards.
- **Headshots:** clear, well-lit, face centered, square or portrait.
- **Numbers:** verified numbers only (MLS, Redfin dashboards, closing statements). Add the source
  line on data videos.
- **Links:** the listing URL, your Redfin profile or loyalty link become QR codes on the end card.
- **Screenshots:** crop to the part that matters. The Studio shows it with callouts and can rebuild
  the numbers as animated charts.
- **Too little or too much?** The checklist tells you exactly what's missing and what to trim.

## 5. Standards (non-negotiables)

| Standard | Why it matters |
|---|---|
| **Keep the end card on** for anything client-facing: name, DRE #, brokerage, Equal Housing Opportunity logo | California license-disclosure rules and brand consistency. Confirm specifics with compliance |
| **Verified numbers only**: no rounding up, no "about" | Trust, and advertising accuracy rules |
| **Privacy setting = Social** for anything public | Shows initials instead of names on leaderboards. For reviews, use first name and last initial |
| **Client consent** before posting a client's name, review or photo | Client trust |
| **Fair Housing language**: describe the home, not who should live there | Fair Housing compliance |
| **Licensed music only**: use the Studio's built-in sound effects or tracks you have rights to | Copyright takedowns |

## 7. Troubleshooting

| Problem | Fix |
|---|---|
| Preview is blank or slow | Use Chrome or Edge, close other heavy tabs, set preview quality to **Fast** |
| MP4 export button is unavailable | Update Chrome or Edge. As a fallback, export the project file and send it for a Claude Code render |
| Text looks crowded | Shorten the headline (6–8 words lands best) or pick a longer length |
| Photo is cropped badly | Use a horizontal photo with the subject centered |
| Starting over | **Reset** in the top bar clears the current project (saved projects stay under **Projects**) |
| Moving to another computer | **Projects → Download**, then open the file on the other computer |
